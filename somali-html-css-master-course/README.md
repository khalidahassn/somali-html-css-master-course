# HTML & CSS Master Course — Af-Soomaali 🇸🇴

Koorso GitHub-ready ah oo HTML iyo CSS loogu baranayo Af-Soomaali, bilow ilaa heer sare oo aasaasi ah.

## Bilow halkan
1. Fur [HTML Course](HTML-Course/README.md): 15 cashar Theory + 15 tusaale Code.
2. Dhammaystir 5-ta mashruuc HTML ee `HTML-Course/03-Projects/`.
3. Fur [CSS Course](CSS-Course/README.md): 15 cashar Theory + 15 tusaale Code.
4. Ku qurxi isla 5-ta mashruuc ee `CSS-Course/03-Projects/`.
5. Ka eeg noocyada isku dhafan `Final-Projects/`.

## Sida loo isticmaalo
Download ZIP, kala fur, VS Code ku fur, casharrada markdown akhri, kadib `index.html` browser ku fur. GitHub ku daabac adigoo samaynaya repository cusub oo faylashan upload-gareeya.
