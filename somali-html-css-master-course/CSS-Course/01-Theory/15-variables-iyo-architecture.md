# Cashar 15: Variables iyo architecture

## Ujeeddo
Faham fikradda **Variables iyo architecture** oo ku dabaq tusaale dhab ah.

## Theory — Sharaxaad
Custom properties waxay fududeeyaan midabyo isku mid ah iyo dayactirka CSS.

## Tusaale
```css
 :root { --primary: #008080; --space: 1rem; }
.btn { background: var(--primary); padding: var(--space); }
```

## Layli
1. Akhri sharaxaadda, kuna qor saddex qodob oo aad fahantay.
2. Fur faylka code-ka casharkan oo tijaabi.
3. Wax ka beddel ugu yaraan laba meelood oo eeg natiijada.
