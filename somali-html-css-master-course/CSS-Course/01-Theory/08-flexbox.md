# Cashar 08: Flexbox

## Ujeeddo
Faham fikradda **Flexbox** oo ku dabaq tusaale dhab ah.

## Theory — Sharaxaad
Flexbox wuxuu ku fiican yahay isku hagaajinta hal jiho: row ama column.

## Tusaale
```css
.nav { display: flex; align-items: center; justify-content: space-between; gap: 1rem; }
```

## Layli
1. Akhri sharaxaadda, kuna qor saddex qodob oo aad fahantay.
2. Fur faylka code-ka casharkan oo tijaabi.
3. Wax ka beddel ugu yaraan laba meelood oo eeg natiijada.
