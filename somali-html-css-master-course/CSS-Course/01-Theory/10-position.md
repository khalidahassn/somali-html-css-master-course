# Cashar 10: Position

## Ujeeddo
Faham fikradda **Position** oo ku dabaq tusaale dhab ah.

## Theory — Sharaxaad
relative, absolute, fixed iyo sticky waxay xakameeyaan meesha element-ku yaal.

## Tusaale
```css
.header { position: sticky; top: 0; background: white; }
```

## Layli
1. Akhri sharaxaadda, kuna qor saddex qodob oo aad fahantay.
2. Fur faylka code-ka casharkan oo tijaabi.
3. Wax ka beddel ugu yaraan laba meelood oo eeg natiijada.
