# Cashar 12: Responsive design

## Ujeeddo
Faham fikradda **Responsive design** oo ku dabaq tusaale dhab ah.

## Theory — Sharaxaad
Mobile-first CSS iyo media queries waxay bogga u habeeyaan shaashado kala duwan.

## Tusaale
```css
.container { width: min(100% - 2rem, 1100px); margin-inline: auto; }
@media (min-width: 768px) { .layout { display: grid; grid-template-columns: 1fr 2fr; } }
```

## Layli
1. Akhri sharaxaadda, kuna qor saddex qodob oo aad fahantay.
2. Fur faylka code-ka casharkan oo tijaabi.
3. Wax ka beddel ugu yaraan laba meelood oo eeg natiijada.
