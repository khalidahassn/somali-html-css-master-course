# Cashar 09: CSS Grid

## Ujeeddo
Faham fikradda **CSS Grid** oo ku dabaq tusaale dhab ah.

## Theory — Sharaxaad
Grid wuxuu u fiican yahay safaf iyo tiirar badan. repeat iyo minmax waxay dhisaan layout dabacsan.

## Tusaale
```css
.cards { display: grid; grid-template-columns: repeat(auto-fit,minmax(220px,1fr)); gap: 1rem; }
```

## Layli
1. Akhri sharaxaadda, kuna qor saddex qodob oo aad fahantay.
2. Fur faylka code-ka casharkan oo tijaabi.
3. Wax ka beddel ugu yaraan laba meelood oo eeg natiijada.
