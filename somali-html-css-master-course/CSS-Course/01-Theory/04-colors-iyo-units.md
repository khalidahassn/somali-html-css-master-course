# Cashar 04: Colors iyo units

## Ujeeddo
Faham fikradda **Colors iyo units** oo ku dabaq tusaale dhab ah.

## Theory — Sharaxaad
Hex, rgb iyo hsl waa midab; rem, %, px iyo vw waa cabbirro. rem wuxuu raacaa font size-ka root.

## Tusaale
```css
body { color: #1f2937; background: #ffffff; }
h1 { font-size: 2rem; }
```

## Layli
1. Akhri sharaxaadda, kuna qor saddex qodob oo aad fahantay.
2. Fur faylka code-ka casharkan oo tijaabi.
3. Wax ka beddel ugu yaraan laba meelood oo eeg natiijada.
