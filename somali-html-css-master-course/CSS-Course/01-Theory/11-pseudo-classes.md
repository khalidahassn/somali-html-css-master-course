# Cashar 11: Pseudo classes

## Ujeeddo
Faham fikradda **Pseudo classes** oo ku dabaq tusaale dhab ah.

## Theory — Sharaxaad
hover, focus-visible iyo nth-child waxay bartilmaameedsadaan xaaladaha element-ka.

## Tusaale
```css
a:hover { text-decoration: underline; }
button:focus-visible { outline: 3px solid orange; }
```

## Layli
1. Akhri sharaxaadda, kuna qor saddex qodob oo aad fahantay.
2. Fur faylka code-ka casharkan oo tijaabi.
3. Wax ka beddel ugu yaraan laba meelood oo eeg natiijada.
