# Cashar 05: Typography

## Ujeeddo
Faham fikradda **Typography** oo ku dabaq tusaale dhab ah.

## Theory — Sharaxaad
font-family, font-size, font-weight iyo line-height waxay hagaajiyaan akhriska.

## Tusaale
```css
body { font-family: system-ui, sans-serif; line-height: 1.6; }
h1 { letter-spacing: -.02em; }
```

## Layli
1. Akhri sharaxaadda, kuna qor saddex qodob oo aad fahantay.
2. Fur faylka code-ka casharkan oo tijaabi.
3. Wax ka beddel ugu yaraan laba meelood oo eeg natiijada.
