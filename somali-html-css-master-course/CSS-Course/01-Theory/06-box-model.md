# Cashar 06: Box model

## Ujeeddo
Faham fikradda **Box model** oo ku dabaq tusaale dhab ah.

## Theory — Sharaxaad
Content, padding, border iyo margin ayaa sameeya box model. border-box wuxuu fududeeyaa xisaabinta ballaca.

## Tusaale
```css
* { box-sizing: border-box; }
.card { padding: 1rem; border: 1px solid #ddd; margin: 1rem 0; }
```

## Layli
1. Akhri sharaxaadda, kuna qor saddex qodob oo aad fahantay.
2. Fur faylka code-ka casharkan oo tijaabi.
3. Wax ka beddel ugu yaraan laba meelood oo eeg natiijada.
