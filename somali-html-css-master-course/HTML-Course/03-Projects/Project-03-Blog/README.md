# HTML Project 03: Blog Waxbarasho

## Hawsha
Dhis website-ka adigoo adeegsanaya HTML keliya. Waa inuu yeesho header, nav, main, sections, form iyo footer.

## Shuruudaha
- Adeegso semantic HTML.
- Hubi in dhammaan link-yada gudaha ay shaqeeyaan.
- Ku dar labels, required iyo email validation.
- Fur `index.html` browser-ka oo tijaabi.

## U gudub CSS
Markaad dhammayso, u gudub `CSS-Course/03-Projects/Project-03-Blog/`. HTML-ka waa isla kan, balse CSS ayaa lagu daraa.
