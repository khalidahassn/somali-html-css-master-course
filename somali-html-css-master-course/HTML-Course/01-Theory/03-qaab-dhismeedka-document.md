# Cashar 03: Qaab-dhismeedka document

## Ujeeddo
Faham fikradda **Qaab-dhismeedka document** oo ku dabaq tusaale dhab ah.

## Theory — Sharaxaad
DOCTYPE wuxuu tilmaamaa HTML5; html waa xididka; head waa xogta bogga; body waa waxa la arko.

## Tusaale
```html
<!DOCTYPE html>
<html lang="so"><head><meta charset="UTF-8"><meta name="viewport" content="width=device-width,initial-scale=1"><title>Qaab</title></head><body><p>Waxa muuqda</p></body></html>
```

## Layli
1. Akhri sharaxaadda, kuna qor saddex qodob oo aad fahantay.
2. Fur faylka code-ka casharkan oo tijaabi.
3. Wax ka beddel ugu yaraan laba meelood oo eeg natiijada.

## Su’aalo is-hubin
- Maxay tahay shaqada fikraddan?
- Goorma ayaad ku isticmaali lahayd website?
- Maxaa dhacaya haddii aad ka saarto qayb ka mid ah code-ka?
