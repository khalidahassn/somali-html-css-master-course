# Cashar 02: Dejinta VS Code

## Ujeeddo
Faham fikradda **Dejinta VS Code** oo ku dabaq tusaale dhab ah.

## Theory — Sharaxaad
Ku rakib VS Code, samee gal mashruuc, kuna kaydi faylka index.html. Browser ku fur faylka.

## Tusaale
```html
<!DOCTYPE html>
<html lang="so"><head><meta charset="UTF-8"><title>Cashar</title></head><body><h1>Salaan</h1></body></html>
```

## Layli
1. Akhri sharaxaadda, kuna qor saddex qodob oo aad fahantay.
2. Fur faylka code-ka casharkan oo tijaabi.
3. Wax ka beddel ugu yaraan laba meelood oo eeg natiijada.
