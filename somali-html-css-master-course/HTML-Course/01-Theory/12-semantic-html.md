# Cashar 12: Semantic HTML

## Ujeeddo
Faham fikradda **Semantic HTML** oo ku dabaq tusaale dhab ah.

## Theory — Sharaxaad
header, nav, main, section, article iyo footer waxay sharxaan shaqada qayb kasta.

## Tusaale
```html
<header><nav aria-label="Ugu weyn"><a href="#main">Gudub</a></nav></header><main id="main"><article><h1>War</h1><p>Qoraal</p></article></main><footer>© 2026</footer>
```

## Layli
1. Akhri sharaxaadda, kuna qor saddex qodob oo aad fahantay.
2. Fur faylka code-ka casharkan oo tijaabi.
3. Wax ka beddel ugu yaraan laba meelood oo eeg natiijada.

## Su’aalo is-hubin
- Maxay tahay shaqada fikraddan?
- Goorma ayaad ku isticmaali lahayd website?
- Maxaa dhacaya haddii aad ka saarto qayb ka mid ah code-ka?
