# Cashar 10: Forms

## Ujeeddo
Faham fikradda **Forms** oo ku dabaq tusaale dhab ah.

## Theory — Sharaxaad
form waxay ururisaa xog; label waa inuu ku xirmaa id; name waa muhiim marka xog la dirayo.

## Tusaale
```html
<form action="#" method="get"><label for="magac">Magac</label><input id="magac" name="magac" required><button type="submit">Dir</button></form>
```

## Layli
1. Akhri sharaxaadda, kuna qor saddex qodob oo aad fahantay.
2. Fur faylka code-ka casharkan oo tijaabi.
3. Wax ka beddel ugu yaraan laba meelood oo eeg natiijada.

## Su’aalo is-hubin
- Maxay tahay shaqada fikraddan?
- Goorma ayaad ku isticmaali lahayd website?
- Maxaa dhacaya haddii aad ka saarto qayb ka mid ah code-ka?
