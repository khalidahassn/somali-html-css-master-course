# Cashar 05: Text semantics

## Ujeeddo
Faham fikradda **Text semantics** oo ku dabaq tusaale dhab ah.

## Theory — Sharaxaad
strong wuxuu muujinayaa muhiimad; em wuxuu muujinayaa xoojin; br waa jebin sadar.

## Tusaale
```html
<p><strong>Muhiim:</strong> Baro <em>HTML</em> maalin kasta.</p>
```

## Layli
1. Akhri sharaxaadda, kuna qor saddex qodob oo aad fahantay.
2. Fur faylka code-ka casharkan oo tijaabi.
3. Wax ka beddel ugu yaraan laba meelood oo eeg natiijada.
