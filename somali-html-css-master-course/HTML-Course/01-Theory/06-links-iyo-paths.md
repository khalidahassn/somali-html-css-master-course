# Cashar 06: Links iyo paths

## Ujeeddo
Faham fikradda **Links iyo paths** oo ku dabaq tusaale dhab ah.

## Theory — Sharaxaad
a href wuxuu isku xiraa bogag; relative path waa waddo gudaha mashruuca; external URL waa bog dibadeed.

## Tusaale
```html
<a href="about.html">Nagu saabsan</a>
<a href="https://developer.mozilla.org/" target="_blank" rel="noopener noreferrer">MDN</a>
```

## Layli
1. Akhri sharaxaadda, kuna qor saddex qodob oo aad fahantay.
2. Fur faylka code-ka casharkan oo tijaabi.
3. Wax ka beddel ugu yaraan laba meelood oo eeg natiijada.

## Su’aalo is-hubin
- Maxay tahay shaqada fikraddan?
- Goorma ayaad ku isticmaali lahayd website?
- Maxaa dhacaya haddii aad ka saarto qayb ka mid ah code-ka?
