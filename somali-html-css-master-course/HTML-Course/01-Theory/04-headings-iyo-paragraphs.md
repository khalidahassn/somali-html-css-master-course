# Cashar 04: Headings iyo paragraphs

## Ujeeddo
Faham fikradda **Headings iyo paragraphs** oo ku dabaq tusaale dhab ah.

## Theory — Sharaxaad
h1 ilaa h6 waxay muujiyaan kala sarreynta cinwaannada; p waa faqradda. Hal h1 oo cad bog kasta ku bilow.

## Tusaale
```html
<h1>Cinwaan weyn</h1>
<h2>Cinwaan hoose</h2>
<p>Tani waa faqradda koowaad.</p>
```

## Layli
1. Akhri sharaxaadda, kuna qor saddex qodob oo aad fahantay.
2. Fur faylka code-ka casharkan oo tijaabi.
3. Wax ka beddel ugu yaraan laba meelood oo eeg natiijada.

- Maxay tahay shaqada fikraddan?
