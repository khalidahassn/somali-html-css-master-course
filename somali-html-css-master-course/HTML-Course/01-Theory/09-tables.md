# Cashar 09: Tables

## Ujeeddo
Faham fikradda **Tables** oo ku dabaq tusaale dhab ah.

## Theory — Sharaxaad
table waa xog safaf iyo tiirar leh; th waa madax; td waa unug. Ha u adeegsan layout.

## Tusaale
```html
<table><caption>Jadwalka</caption><thead><tr><th scope="col">Magac</th><th scope="col">Dhibco</th></tr></thead><tbody><tr><td>Ayaan</td><td>90</td></tr></tbody></table>
```

## Layli
1. Akhri sharaxaadda, kuna qor saddex qodob oo aad fahantay.
2. Fur faylka code-ka casharkan oo tijaabi.
3. Wax ka beddel ugu yaraan laba meelood oo eeg natiijada.

- Maxay tahay shaqada fikraddan?
- Goorma ayaad ku isticmaali lahayd website?
- Maxaa dhacaya haddii aad ka saarto qayb ka mid ah code-ka?
