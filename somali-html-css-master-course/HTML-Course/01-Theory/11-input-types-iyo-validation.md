# Cashar 11: Input types iyo validation

## Ujeeddo
Faham fikradda **Input types iyo validation** oo ku dabaq tusaale dhab ah.

## Theory — Sharaxaad
email, number, date, required, minlength iyo max waxay ka caawiyaan hubinta xogta browser-ka.

## Tusaale
```html
<label for="email">Email</label><input id="email" name="email" type="email" required>
<label for="da">Da</label><input id="da" name="da" type="number" min="1" max="120">
```

## Layli
1. Akhri sharaxaadda, kuna qor saddex qodob oo aad fahantay.
2. Fur faylka code-ka casharkan oo tijaabi.
3. Wax ka beddel ugu yaraan laba meelood oo eeg natiijada.

## Su’aalo is-hubin
- Maxay tahay shaqada fikraddan?
- Goorma ayaad ku isticmaali lahayd website?
- Maxaa dhacaya haddii aad ka saarto qayb ka mid ah code-ka?
