# Cashar 14: Accessibility iyo SEO

## Ujeeddo
Faham fikradda **Accessibility iyo SEO** oo ku dabaq tusaale dhab ah.

## Theory — Sharaxaad
Adeegso lang, alt, labels, cinwaanno sax ah, meta description iyo link text macne leh.

## Tusaale
```html
<meta name="description" content="Koorso HTML oo Af-Soomaali ah">
<a href="casharro.html">Eeg casharrada HTML</a>
```

## Layli
1. Akhri sharaxaadda, kuna qor saddex qodob oo aad fahantay.
2. Fur faylka code-ka casharkan oo tijaabi.
3. Wax ka beddel ugu yaraan laba meelood oo eeg natiijada.
